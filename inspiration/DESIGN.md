# 博客灵感集

四套可切换、可交互的原创个人博客示例，使用演示文案。部分文章主题来自相邻 blog 文件夹中的 Agent 日志，未发布原文。

- 01 纸感编辑部：纸色与橄榄绿、宋体大标题、原创几何插画、精选文章。
- 02 极简开发者：窄栏介绍、日期文章列表、分类与搜索。
- 03 数字花园：原创植物线稿、笔记生长阶段、手札布局。
- 04 深色实验室：石墨黑、柔和绿色、Agent 流程图、实验卡片。

所有方案支持文章阅读弹窗、关于展开、设计笔记与本地收藏。布局适配手机，尊重减少动态效果的偏好。Google Fonts 不可用时会回退到系统字体。

## 参考来源（2026-10-12 检索）

- https://antfu.me/ — 个人介绍、项目与文章的组织。
- https://maggieappleton.com/ — 视觉文章、数字花园、不同成熟程度的笔记。
- https://www.joshwcomeau.com/ — 用图解与交互解释技术。

借鉴内容组织与表达思路，不复刻原站，不使用原站代码或图片。SVG 图形均为本项目原创。

## 本地运行

在此目录运行 `node serve.mjs`，打开 http://127.0.0.1:4173 。亦可直接打开 dist/index.html。

静态文件位于 dist，无构建或依赖安装步骤。

## 回退方法

在最新 main 上撤销一个页面改动，例如首页介绍：

```sh
git pull --ff-only origin main
git revert bf0d4b8
git push origin main
```

如果要撤销全部六项页面改动，按从新到旧的顺序撤销：

```sh
git revert 4db1e97 f6a69be 4a27e68 bf0d4b8 283f1ae cc2f2aa
git push origin main
```

这样保留历史与新文章。基础样式加载入口 `c0e0fb5` 可保留，回退后的独立样式文件为空注释，不改变原页面。如果还要撤销加载入口，应先撤销六项页面提交。

只查看改动前版本，可创建独立工作目录：

```sh
git worktree add --detach ../P3R_website-before-refresh before-style-refresh-20260930
```
